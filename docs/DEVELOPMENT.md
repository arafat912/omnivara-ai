# Development

1. Install Python 3.11+ and Node.js 20+.
2. Copy `.env.example` to `.env` and add API keys locally.
3. Start FastAPI from `backend/`.
4. Start Next.js from `frontend/`.
5. Start Expo from `mobile/`.

Never commit `.env`, API keys, passwords or private credentials. Authentication, chat persistence and production monitoring are not implemented yet.
